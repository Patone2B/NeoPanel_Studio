À propos de NeoPanel Studio

NeoPanel Studio 1.2.2 transforme un ancien smartphone, une tablette ou un petit écran secondaire en tableau de bord de contrôle pour un PC Windows.

Depuis le téléphone, il est possible de :

  • surveiller l’utilisation du CPU, du GPU et de la RAM ;
  • afficher l’heure, la météo et les informations système ;
  • contrôler la musique et le volume ;
  • lancer des applications ;
  • utiliser des raccourcis pour DaVinci Resolve, OBS et le navigateur ;
  • configurer les chemins des applications ;
  • partager des notes entre le PC et le téléphone ;
  • utiliser l’interface sur le réseau local, sans compte ni serveur externe.

Le PC héberge l’interface et le téléphone s’y connecte avec l’adresse locale ou le QR code. Les données de contrôle restent sur le réseau local, à l’exception des services externes configurés par l’utilisateur, comme OpenWeather.

Pour contribuer au projet, consultez le dépôt GitHub.
