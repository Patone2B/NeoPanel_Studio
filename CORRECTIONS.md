NeoPanel Studio 1.2.2 — dernières corrections avant publication

- La clé OpenWeather déjà sauvegardée est désormais conservée lorsque le champ est laissé vide.
- L'interface indique clairement si une clé API est enregistrée.
- La détection IPv4 accepte les formats IPv4, 4 et "4" selon la version de Node.js.
- La page Réseau n'affiche plus de message laissant croire que l'application est cassée lorsque Windows ne remonte pas toutes les interfaces.
- Une application absente affiche : « Application introuvable. Configure son chemin dans Config apps. »
- Le serveur vérifie maintenant que le fichier .exe ou .lnk existe avant de tenter son lancement.
- Le README GitHub a été entièrement refait.
- L'intégration GPU avancée est présentée dans la section « À venir », et non comme une fonction pleinement intégrée.
- Ajout de .gitignore et CHANGELOG.md.

Validation effectuée : syntaxe de server.js, main.js et public/app.js.
